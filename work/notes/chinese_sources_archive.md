# Local Chinese source archive

Collected on 2026-10-04 at the user's request. Start with
[`work/research/chinese_sources/2026-10-04/README.md`](../research/chinese_sources/2026-10-04/README.md).

The archive contains downloaded public pages, extracted text, search-index snapshots,
Bilibili video descriptions and episode lists, available public comments, and guide
screenshots. Each downloaded response has a source URL, retrieval timestamp and
SHA-256 hash. The existing Reddit workbooks are inventoried by hash rather than
downloaded again.

The entire `work/research/chinese_sources/` directory is ignored by Git because it
contains third-party material. It is local research evidence, not a redistributable
part of the translation. A fresh clone will not include these snapshots.

Consult the archive index for access failures and partial records. In particular,
search-index text is not a complete live forum scrape, video descriptions are not
transcripts, and a downloaded document shell does not mean its contents were obtained.
Legacy guides and release announcements describe different versions; verify claims
against the untouched Chinese v4.0.3 ROM before changing player documentation.

Initial findings are in [the independent-source review](chinese_sources_review_2026-10-04.md).
