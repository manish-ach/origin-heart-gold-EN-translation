**Engine note (verified in the arm9 code, applies to every chapter):** the script command `HidePerson` hides an object **permanently**. Its handler (command 101 → `0x0205D57C`) sets the object's hide flag with the same function the `SetFlag` command uses (`0x0203FB4C`) before removing the object. Earlier reviews had assumed the opposite (the object returns on map reload); entries that depended on that were corrected, and the hack finding D-1396 (repeatable Pewter Charmander) was withdrawn.

## 01 Pallet Town to Pewter City

### Pallet Town: send-off gifts: the unlock condition is wrong (verified by hand; the user got no Charcoal following the guide)

**Guide says:** the shared gift flag (768) "is cleared when Daisy hands you the Town Map (or after Mom's money talk), so talk to Daisy first."

**Actually:** flag 768 is set at new game (file 149 @512), so every gift starts locked. Unlocking it needs Mom **and** Daisy:
1. After you have your starter, talk to Mom. She gives the Running Shoes (only before the first Badge; file 842 @6123 clears 767). For Bulbasaur players her Poliwhirl line (L7422) clears 768 straight away.
2. Get the Town Map from Daisy (flag 408).
3. Whichever you do last unlocks the gift. Daisy clears 768 after the Town Map only if 767 is clear (file 736 @452 → L1781). Otherwise, talking to Mom again and finishing her savings question clears 768 once 408 is set (file 842 L8826/L8800 → L9557).

Until then, the Charmander gift man says only line 439#19 ("kid dragged into the grass"; file 733 script 13, which also needs flag 1804 and flag 1287, and gives Charcoal, item 249, at L1924). The Eevee man (Pikachu, script 1) goes to another line (L1015) instead of the Light Ball.

**Also:** the closing trigger (flag 1088) fires as soon as you enter Viridian City from the Route 1 gatehouse, not "the first time you walk west past the Pokémon Center" (see the Mankey entry).

**Suggested text:**
> **Who gets it / when:** each starter gets one gift. All of them close for good once Blue's scene in Viridian City has played (flag 1088: it triggers as soon as you enter Viridian from the Route 1 gatehouse). They share one "gift received" flag (768), which the game sets at the start, so every gift is locked until you unlock it:
> 1. After you have your starter, **go home and talk to Mom**. She gives you the Running Shoes (only before your first Badge; this clears flag 767). Bulbasaur players are done now: her Poliwhirl line unlocks the gift.
> 2. **Get the Town Map from Daisy** in Blue's house (flag 408).
> 3. Whichever of the two you do last unlocks the gift: Daisy clears 768 if you've already had Mom's Running Shoes talk. If you saw Daisy first, talk to Mom again and answer her savings question.
>
> Then talk to the gift-giver (table below), before you enter Viridian City. Until the gift is unlocked, the man by the south fence only talks about the kid dragged into the grass, and the Eevee man only gives flavour lines.

Source line: script files 149 (new game sets 767/768), 733 (Eevee man script 1 checks 1088/768/408/1288; fence man script 13 checks 1804/1088/1287/768, Charcoal at L1924), 842 (Mom L6123 clears 767, Bulbasaur branch L7422 clears 768, savings talk L8826/L8800 → L9557 clears 768 once 408 is set), 736 (Daisy L452: clears 768 at L1781 only if 767 is clear), 738 (Oak's lab sets 1287 for Charmander), 739 (flag 1088).

### Viridian City: Mankey thief: the "can be lost" warning is wrong (verified: script review plus map collision)

**Guide says** (quest section Notes and known-issues bullet "Mankey thief can be lost"): Blue's Viridian scene hides the Mankey for good, and if you've started the quest but not beaten it, the Fast Ball is lost; "beat Mankey right after talking to the keeper."

It never touches the quest's other flags (1335/1336). The only other code that could interfere (Route 22 scripts 9/10, Viridian scripts 27/30) isn't run by any object or trigger. (Collision read from map data; ledges/HM obstacles not modelled; untested in game.)

Blue's scene in Viridian also sets the Mankey's hide flag, but it can't cut the quest short: its trigger tiles (≈1023–1026,266) cross the only path north from the Route 1 gatehouse, so the scene always plays before you can reach the keeper. By then the flag was already set on Route 1, so nothing changes (read from the map's collision data; ledges and HM obstacles not modelled; untested in game).

**Suggested text, known-issues bullet:**
> **Blue's Viridian scene sets the Mankey thief's hide flag (file 739, L3274, `SetFlag 1330`). Not reachable, harmless.** If the scene played while the Mankey quest was running, the Mankey would vanish and the Fast Ball would be lost. But the scene's trigger (script 14, ≈1023–1026,266, var 0x4075 == 0) sits on the only path north from the Route 1 gatehouse, so it always plays before the lamp keeper (≈1019,255) can start the quest. The Route 1 tutorial has already set flag 1330 at that point, so the scene changes nothing. It never touches the quest's other flags (1335/1336). (Read from the map's collision data; ledges and HM obstacles not modelled; untested in game.)

## 10 Radio Tower, Ecruteak City and Olivine City

Checked by a first reviewer, then independently re-derived by a second (flags decimal). The first reviewer's "reading the Pidgey letter before the Plain Badge makes the Wise Glasses unobtainable" was **refuted**: Route 35 is physically sealed until the Plain Badge (the Goldenrod gatehouse boy and his Luxray, the Route 36 tree and the Mahogany roadblock), so the letter is always read after the badge.

### Route 35: the Pidgey letter / Ecruteak: the letter-writer and the Wise Glasses
- The writer is a **woman** (not "the wheelchair man… his Pidgeot"), in the house behind door **≈407,183**, near the east gate, not the Pichu house.
- The letter (380#44) only says her health keeps her indoors; there's no "sick child". Suggested: "a stay-at-home writer who can't go out".

### Route 35 → 36: puppy love
- The mother asks whenever you meet her; there's no Plain Badge condition in her script (in practice Route 35 opens with the Plain Badge anyway). Suggested: "any time".
- In the harsh ending the boy and his Weepinbell don't simply disappear: they move into the gatehouse beside the mother.

### Blackthorn: the runaway Dragonair trainer
- The parent is the **father** (626#54 我和孩子他妈, "his mother and I"): change "mother/woman" to "father".

### Route 36 / National Park extras: Will and Karen

### Burned Tower → Ecruteak Gym

### Ecruteak: the Murkrow

### Route 39: the Sunflora story / MooMoo Farm investigation
- The Miltank are **already sick when you first reach Johto** (Prof. Elm's send-off makes them sick, and the League HQ round-3 dispatch does too). The farmer offers the investigation whenever they're sick; **nothing checks for League HQ round 3**. There's no "before round 3, the farm is normal" window.
- The Olivine seal girl is behind door **≈292,241** (west room).
- Not verified, possible hack bug: if you finished the Dream World before the League HQ round-3 dispatch, that dispatch would make the Miltank sick again for good (the Dream World cure runs once), reverting the milk stall, the seal girl and the Sunflora old lady.

### Olivine: the café dishes / Super Rod
- The fisherman is behind door **≈273,247**; the door at ≈292,241 is the seal girl's room.

### Olivine Gym: Jasmine
- **Add:** the Metal Burst tutor is gone from the Mineral Badge until Amphy is cured.

### Route 38 → Olivine small extras

### Ecruteak: the lantern riddles
- Cosmetic: a wrong answer at riddle 4 or 5 makes Grandpa repeat riddles 2–5 before telling you that you failed. *(Hack finding.)*

### Mahogany: where the Rainbow Wing is
- "Mahogany Town, map 133" means nothing to a player: it's an item ball in the Team Rocket hideout room under Mahogany (the room with the Persian statues and Archer's notebook, exit ≈537,174).

### Known issues (Ecruteak and Olivine)
- **Flag 1061 bullet:** "reading the Pidgey's letter lets Nurse Joy give her gift again" is false; that Nurse Joy is hidden by a flag nothing clears. The letter can't be read before the Plain Badge anyway.

### Chinese / translation

## 08 Cherrygrove City to Azalea Town

Checked by a first reviewer, then independently re-derived by a second (18 of 20 confirmed, 2 partly; the Route 32 reachability check used corrected collision data). Sections both found correct are not listed.

### Cherrygrove City: Crystal, the orphanage and Rhett's Slugma
- **Reward is not "story only":** if you answer **Yes** to "Will you help hold back the Slugma?" and win (trainer 745: Slugma Lv. 28, 25, 25), you get **5 Heal Balls** (file 847 L6549–L6561). No → Crystal handles it, no item. A loss whites you out. Suggested: "Reward: 5 Heal Balls if you help hold back the Slugma and win."

### Route 30 → Route 31: the wild Chikorita
- **Missable in a second way:** the Chikorita's hide flag (1323) is also set by **Brock in the Pewter Museum** every time you talk to him (file 753 script 16) while his siblings' quiz isn't finished. Talking to him after the orphanage scene but before the Route 30 event removes the Chikorita for good. Suggested: "Don't talk to Brock in the Pewter Museum between the orphanage scene and this event." *(Hack finding D-1424.)*

### Violet City: Tamao and Crystal
- **"Tamao reappears later (her battle flag is cleared again on Route 34)": wrong.** Tamao and Crystal are hidden by flag 739, which the ceremony sets and nothing clears. Flag 1839 on Route 34 (file 237) is a different object's hide flag (a Totodile). Drop the sentence; both battles are gone after the ceremony.

### Sprout Tower: the Elder
- The Elder's team (Victreebel, Carnivine, Ludicolo, Shiftry, Cacturne, Tangrowth, Lv. 81–82) is a **Grass** team. Only Ludicolo is part Water. Replace "Grass/Water team".

### Violet City: the repentant thief
- **"Every answer ends the conversation the same way; nothing else checks it": wrong.** Answers 1–3 set his hide flag (1827), so he's **gone the next time the map loads** (until then he says "Thanks for clearing up my doubts"). "Not my problem" sets nothing, so you can ask again.

### Violet City: the runaway Marill
- **Reward line:** on the Talk route with the Union Cave rescue, the owner and Marill are back in Violet **straight after the Union Cave win** (file 56 L2848/L2852), not "after the Ilex scene". The Ilex scene only repeats the same flag changes.

### Pokémon Academy
- It's **five questions from five students** (then Youngster Ward battles you), not four students. The table already has five rows.

### Violet City: Gyro Ball TM for the Forretress kid
- **"The TM is used up": wrong.** Nothing takes TM74 (file 854 L3872–L3895 only sets flag 1850); you keep it. *(Hack finding D-1425.)*

### Violet Gym: Falkner's rules
- **"Every one is Flying-type" is how it's meant, not how it's checked.** The script refuses you if any of **692 listed non-Flying species** is in your party. The list covers every non-Flying species up to Sinnoh but misses about 226 later ones (e.g. Patrat, Yungoos), which pass. Rotom and Shaymin are on the list, so Rotom-Fan and Shaymin Sky Forme are refused even though they're Flying. *(Hack finding D-1426.)*
- **After your final Hall of Fame entry** (flag 2261) Falkner is away on **Wednesdays** (file 856 script 1).

### Route 32: access (applies to every Route 32 entry south of the railway)
- The railway crew (flag 1904, ≈475–477,305) blocks the **only** path south from Violet until the end of the Molly chapter (file 51 L4253). Everything south of it waits until then: the fire-breather, the Friday sibling, the Quick Powder, the Mareep girl, the Hoppip owner, the "eat Pokémon" man, the Pokémon Center and Union Cave. The guide mentions the crew leaving only in the Molly entry; say it at the top of the Route 32 entries. (Approach from the south, via Azalea and Union Cave, wasn't traced.)

### Route 32: the fire-breather
- **"The script checks for every non-Fire species": not quite.** It checks every non-Fire species up to Sinnoh **except Carnivine and Magnezone**, and **no species after Sinnoh**, so those pass too. *(Hack finding D-1426.)*
- His team: **Charizard 62, Typhlosion 63, Blaziken 64, Infernape 65**.

### Route 32: "Should people eat Pokémon?"
- **You get exactly one item, not both.** The man stands south of the railway crew, so you can only reach him after the Molly chapter, which needs the Sprout Tower ceremony. By then the shared flag (1849) has already been cleared for the last time, and Crystal's Violet battle is gone (flag 739). So the "before Sprout Tower" and "both items" notes can't happen. Suggested: "Yes gives Leftovers, No gives Sharp Beak. One item only." Also rename the heading ("both answers give an item" reads like you get both).

### Ruins of Alph: the missing Molly
- **Step 6:** both battles are **Double Battles against two copies of Entei's team** (trainer 671 twice, file 51 L818 and L2623), with a single heal before the first. Losing either whites you out.

### Route 32 extras: Quick Powder
- **"It appears to come back every time": wrong.** The script runs HidePerson on the item, which sets its hide flag (1314) permanently. Nothing sets it back. One Quick Powder.

### Union Cave and Route 33 teams
- **Goh (Union Cave):** six Pokémon: Manectric 84, Slowbro 85, Dugtrio 84, Scizor 85, **Slaking 84, Tangrowth 85**.
- **Hiker Jeb:** also **Probopass 82 and Aggron 83**.
- **Route 33 Ace Trainer:** also **Wailord 83 and Pelipper 82**.

### Azalea Gym: Bugsy's list
- **Altaria and Tropius are bad examples:** in this hack Altaria is Dragon/Fairy and Tropius is Grass/Dragon, so they're not Flying types. The real gaps are **Hippowdon** (Ground/Rock here) and 55 Fire/Flying/Rock species from after Sinnoh. *(Hack finding D-1426.)*

### Azalea Town: the Charcoal Kiln
- The Kiln door is **≈419,468**. ≈399,454 is Kurt's room.
- Black Belt Collier also has **Lickilicky Lv. 65**.
- **The girl and the Spinarak (≈415,469)** stand outside the **Charcoal Kiln**, not Kurt's house.
- *(Checked: "Kimono Girl Sakura" at the Ilex gatehouse is correct in the WIP build.)*

### Known issues (Cherrygrove to Azalea)
- **Quick Powder bullet: wrong.** HidePerson sets the item's own flag 1314, so it doesn't come back. Remove it.
- **Flag 1849 bullet: wrong.** Both items can't be had (see above). Remove it.
- **New bullets:** Brock and the Chikorita (D-1424); the Gyro Ball TM kept (D-1425); the incomplete species lists for Falkner, the fire-breather and Bugsy (D-1426).

## 13 Dungeons, Battle Tower and game-wide events

Checked by a first reviewer, then independently re-derived by a second, including the arm9/overlay code (11 of 12 confirmed, 1 partly). Sections both found correct are not listed.

### Mt. Moon Square: the Clefairy dance
- **It repeats.** "Whether the dance can be seen again … is untested": flag 2741 is a daily flag. The game clears flags 2720–2911 on every new day (arm9 0x0203FBAC). So the dance and a **new Moon Stone** come back **every Monday night**, and because the flag also clears at midnight, it can play again between 00:00 and 03:59 on Tuesday.
- **New warning:** pick up the Moon Stone before you leave. Re-entering the dance room re-hides the ball (flag 664, map 513 script 1), and for the rest of that day the doorway leads to the normal Square.
- Minor: the doorway is switched when the entrance map loads. If 8 p.m. passes while you're standing in the entrance, go out and back in.

### Ruins of Alph: panels and walls
- **Drop "the original game's trigger; untested"** for the Kabuto (Escape Rope), Aerodactyl (Flash) and Omanyte (Water Stone) walls. The hack's code is the vanilla check. Say: "**Stand right in front of the wall, facing it,** and use …". The Escape Rope isn't used up.
- **"Unown start to appear in the ruins":** they appear in the **Underground Hall** once any panel is solved. After the Molly chapter they also appear in the large area further down (see next bullet).
- **The dream-world hall has more exits.** Its door (6,17) always leads back to the **Kabuto chamber**, whichever wall you came through. Stepping on (6,3) takes you down to a lower hall with a statue and a passage onward. The passage is blocked by statues until the end of the Molly chapter (flag 1904).
- **Unown Report: no notes at all.** The Research Center's notes need a counter that the hack never increases (the code that did it in the original game is unreachable). The researcher only ever gives his "about 1,500 years old" line (71#32). Replace "up to four notes" and the "fifth and later notes" sentence. *(Hack finding D-1427.)*

### Forest of Time: the maze
- The route is right. Small additions: the "one earlier stage" (var 2) is set by the Ilex Forest bug hunt, not the Sammy chapter. At var 4, clearing F's bottom-middle exit (49,50) drops you one step below clearing C's top exit. During the Sammy chapter, Sammy, Celebi and the ranger stand on the entrance clearing's top-middle exit and block it until their scene moves on.
- Worth a warning: the bug hunt and the Forest of Time share their progress variable, so entering the Forest of Time **during** the Ilex bug hunt may play the wrong scene. Untested. *(Hack finding D-1429.)*

### Lake of Rage: the calm day
- **The visitors need the Petrel scene too.** Clearing the Rocket HQ makes Wednesdays calm (flag 202), but Carson, Wesley and the ground item are hidden until the **Petrel scene at the lake guardian's house** (var 0x40B2 = 5, file 935 L551). Suggested: "on Wednesdays, once you've cleared the Rocket HQ and seen the Petrel scene."
- **The "Heart Scale/PP Max man" is an item ball** (≈539,73): Heart Scale 7:00–18:59, PP Max 19:00–6:59. It comes back on a later calm day (same as the chapter 12 erratum).
- **The quote "the storm pauses on Wednesdays" isn't a game line.** Quote 71#59 ("the downpour over the Lake of Rage stops for one day every Wednesday") or 396#1, or drop the quotation marks.

### Field moves: which Badge each one needs
- **Surf at the water needs the Rainbow Badge** (Erika). "No Badge check when you examine the water" is wrong.
- **Fill in the party-menu checks** (traced in the hack's code): Cut: Cascade Badge (Misty); **Fly: Marsh Badge (Sabrina)**; Surf: Rainbow Badge (Erika); Strength: Thunder Badge (Surge); Rock Smash: Boulder Badge (Brock); Waterfall: Earth Badge (Giovanni); Rock Climb: Rising Badge (Clair); Whirlpool: Volcano Badge (Blaine); **Flash: no Badge**. (Badge ids 1, 4, 3, 2, 0, 7, 15, 6.)
- **"A Pokémon must know the move" is wrong for the overworld prompts.** The hack changed the "which Pokémon knows this move" command to return your first healthy Pokémon, and the water and Waterfall checks no longer test for the move. So Surf, Waterfall and the field prompts (Cut tree etc.) work with your lead Pokémon even if none knows the move; only the Badge is needed. The party menu still lists only moves a Pokémon knows. Untested in game, possibly an intended HM-free change. *(Hack finding D-1428.)*

### Known issues (dungeons and common)
- **Bullet 1 (hidden rooms):** the rooms are unreachable (right), but the report never gives any note, not "stops at the fourth".
- **Bullet 2:** "never passes 6" → "**never leaves 0**".
- **New bullets:** the Unown Report (D-1427); HM-free field moves (D-1428); the shared Forest of Time variable (D-1429); **Island Forest (Six Island) has no grass or surf encounters until you've solved a Ruins of Alph panel** (it's still inside the original game's Ruins of Alph encounter check; fishing works) (D-1430).

### Chinese / translation
- No quoted line contradicts the Chinese; no lyrics.
